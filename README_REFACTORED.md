# Reuse+ - Sistema de Gerenciamento de Inventário\n\n## 📋 Descrição\n\n**Reuse+** é um sistema completo de gerenciamento de inventário que permite controlar entrada e saída de itens, com autenticação segura e interface intuitiva.\n\n## 🎯 Funcionalidades\n\n- ✅ Autenticação de usuários com JWT\n- ✅ Gerenciamento de itens de inventário (CRUD)\n- ✅ Registro de movimentações (entrada/saída)\n- ✅ Dashboard com relatórios\n- ✅ Interface responsiva\n- ✅ Suporte a múltiplos usuários\n- ✅ Acesso administrativo restrito\n\n## 🏗️ Arquitetura\n\n### Backend (.NET 10.0)\n\n```\nReusePlusApi/\n├── Controllers/          # Controladores da API\n├── Models/              # Modelos de dados\n├── DTOs/                # Data Transfer Objects\n├── Services/            # Lógica de negócio\n├── Repositories/        # Padrão Repository\n├── Data/                # Contexto do banco\n├── Constants/           # Constantes da aplicação\n├── Exceptions/          # Tratamento de exceções\n└── Program.cs           # Configuração principal\n```\n\n### Frontend (HTML/CSS/JavaScript)\n\n```\nfrontend/\n├── index.html           # Página inicial\n├── login.html           # Página de login\n├── cadastro.html        # Página de cadastro\n├── principal.html       # Dashboard principal\n├── css/                 # Estilos\n├── js/                  # Scripts\n│   ├── config.js        # Configurações\n│   ├── services.js      # Serviços\n│   ├── app.js           # Script principal\n│   └── login.js         # Script de login\n└── assets/              # Imagens e recursos\n```\n\n## 🚀 Como Iniciar\n\n### Requisitos\n\n- .NET 10.0 SDK\n- PostgreSQL 12+\n- Node.js (opcional, para desenvolvimento frontend)\n\n### Backend\n\n```bash\n# Navegar para o diretório do backend\ncd backend/ReusePlusApi\n\n# Restaurar dependências\ndotnet restore\n\n# Executar migrações do banco de dados\ndotnet ef database update\n\n# Iniciar servidor\ndotnet run\n```\n\nO servidor iniciará em `http://localhost:5094`\n\n### Frontend\n\n1. Abrir `frontend/index.html` em um navegador web\n2. Ou servir com um servidor local:\n\n```bash\n# Usando Python 3\npython -m http.server 8000 --directory frontend\n\n# Ou usando Node.js\nnpx http-server frontend\n```\n\n## 🔐 Autenticação\n\n### Credenciais de Admin Padrão\n\nDefina as credenciais no `appsettings.json`:\n\n```json\n{\n  \"AdminCredentials\": {\n    \"User\": \"admin@reuseMais.com\",\n    \"Password\": \"admin123\"\n  },\n  \"AdminSecret\": \"sua_chave_secreta_aqui\"\n}\n```\n\n## 📚 Endpoints da API\n\n### Autenticação\n\n- `POST /api/auth/login` - Login\n- `POST /api/auth/register` - Registrar usuário\n- `POST /api/auth/register-admin` - Registrar admin (requer chave secreta)\n\n### Itens\n\n- `GET /api/item` - Listar todos os itens\n- `GET /api/item/{id}` - Obter item específico\n- `POST /api/item` - Criar novo item\n- `PUT /api/item/{id}` - Atualizar item\n- `DELETE /api/item/{id}` - Deletar item\n\n## 🛠️ Padrões e Boas Práticas\n\n### Backend\n\n- **Clean Code**: Código limpo e legível\n- **SOLID Principles**: Arquitetura robusta\n- **Repository Pattern**: Abstração de dados\n- **Dependency Injection**: Injeção de dependências\n- **Exception Handling**: Tratamento centralizado de erros\n- **DTOs**: Separação entre modelos e transferência de dados\n- **Data Validation**: Validação em modelos e DTOs\n\n### Frontend\n\n- **Semantic HTML**: Estrutura semântica\n- **Responsive Design**: Adaptável a diferentes telas\n- **Service Layer**: Abstração de API\n- **Configuration Management**: Configuração centralizada\n- **Error Handling**: Tratamento de erros com feedback\n- **Accessibility**: Preocupação com acessibilidade\n\n## 📝 Configuração do Banco de Dados\n\n### Variáveis de Ambiente\n\nCrie um arquivo `.env` ou configure no `appsettings.json`:\n\n```json\n{\n  \"ConnectionStrings\": {\n    \"DefaultConnection\": \"Host=localhost;Database=reuseMais;Username=postgres;Password=sua_senha\"\n  },\n  \"Jwt\": {\n    \"Key\": \"sua_chave_jwt_secreta_aqui\",\n    \"Issuer\": \"ReuseMaisApi\",\n    \"Audience\": \"ReuseMaisApp\"\n  }\n}\n```\n\n## 🧪 Testes\n\n```bash\n# Executar testes unitários\ndotnet test\n```\n\n## 📦 Build e Deploy\n\n### Backend\n\n```bash\n# Build de release\ndotnet build -c Release\n\n# Publicar\ndotnet publish -c Release\n```\n\n### Frontend\n\nO frontend é estático e pode ser hospedado em qualquer servidor web.\n\n## 📄 Licença\n\nMIT License -
